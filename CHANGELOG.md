# Changelog

## 1.2.0

- Optional two-minute wallpaper rotation, enabled by default; lifecycle-aware timer and single-decoder transitions.
- Bounded video buffering, disabled wallpaper audio/text decoding and stable video surface attachment.

- Shared implementation with distribution-specific media and preset profiles.
- Optional cinema and series sources; public defaults remain empty.
- English game menus, category labels and dynamic counts; Android-safe template parsing.
- Guava security update and expanded instrumentation coverage.
- Refreshed gallery with actual installed applications.

## 1.0.0 — Public edition

- Fresh public repository and separate Android application ID.
- Three original 4K abstract loops; synthetic game and welcome sounds.
- Local video/audio import, favorites, HDMI, Jellyfin, albums and two minigames.
- User-configured RSS/Atom feeds; no default publisher scrapers.
- Documented TVmaze schedule API with attribution; optional Open-Meteo weather.
- Manual city selection, offline license viewer and documented privacy flows.
- Source/media audit, build/lint/unit/integration checks and release provenance.

Not bundled: proprietary media, personal albums, account tokens, private build
history, IP-location lookup or cinema HTML scrapers. No migration from a private
development installation is performed automatically.
