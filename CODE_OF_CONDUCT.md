# Community conduct

Help people participate constructively. Discuss code and behavior without personal attacks, harassment or discrimination. Respect privacy: do not post personal data or credentials. Do not submit content you are not entitled to redistribute.

Maintainers may remove harmful content, close disruptive discussions or restrict participation. For private concerns, contact the repository owner through their GitHub profile; report security vulnerabilities through the private security-reporting channel described in SECURITY.md. Do not put private reports into public issues.
